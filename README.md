A tiny Python program that writes one word to `/output/entry.txt`: the entrant's own make.fun username, `zenunderoad17` — 13 characters, a single word, nothing else. This bounty fixes its own entry: the rules ask for the entrant's own handle and only that, so there was nothing to draft or duel. Why this handle is the entry, and why a few look-alike handles would be invalid, is written up in `candidates.md`.

## Run it

```sh
python3 main.py
```
